1. セーブを用意（全29材料・在庫9・Dexなし）

ゲームを開く(セーブはそのまま)

2. ゲームでやること

  1. ホーム →「フリークッキング」→ 生地 → ソース → チーズ → 具材まで進める（具材の画面に 🧺食材庫 ボタンが出る）。
  2. 🧺食材庫 → 検索欄をタップ。以降は HV 手順の A / B に従う。

3. 数値を取りたいとき（Mac の Safari Web Inspector）

iPhone を Mac に USB 接続 → Safari「開発」→ iPhone → 対象ページ → コンソールに下を貼り付け。以降 __snap("ラベル") で現在値を記録、最後に __dump() の出力をコピー。Macが無ければ動画だけで可。standalone も「開発」メニューに出ます。
